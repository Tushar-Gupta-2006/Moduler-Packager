🛠️ Multi-Utility Toolkit

A Python-based command-line application that provides multiple useful utilities in one program.

✨ Features

🕒 Datetime & Time

Current date/time

Date difference

Custom date formatting

Stopwatch

Countdown timer

🧮 Mathematical Operations

Factorial

Compound interest

Trigonometric calculations

Area of circle and rectangle

🎲 Random Data

Random number

Random list

Random password

6-digit OTP

🆔 UUID Generator

Generate unique UUIDs

📁 File Operations

Create

Write

Read

Append files

🔍 Module Explorer

Explore Python module attributes using dir()

🛠️ Technologies

Python 3

datetime

time

math

random

uuid

os

importlib

No external libraries are required.

🚀 How to Run
python main.py

🎯 Purpose

This project is created to practice Python functions, loops, exception handling, file handling, and built-in modules.
